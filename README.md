# Beach3Blog
## 🌊 Beach3 — Personal Website
This is my personal website built with Astro
I wanted to create a warm and welcoming site that reflects my love for the ocean 🌊 and my work in IT 💻.

## 🚀 Features
- ⚡️ Astro — Static site generator for fast and modern websites
- 🎨 Custom design with light & dark modes
- 📱 Responsive (optimized for desktop & mobile)
- 🌊 Ocean-inspired gradients & background themes
- 🔗 Easy to extend with Markdown/MDX for blog posts

## 🛠 Tech Stack
- [Astro](https://astro.build/)
- [astro/portfolio](https://github.com/withastro/astro/tree/latest/examples/portfolio?on=github)

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
